# Scale-resolved local closure: code and data

This directory contains the analysis and figure-generation code for **“Scale-resolved local closure reveals hierarchical dynamical organization.”** This repository contains the analysis and figure-generation code accompanying the manuscript “Scale-resolved local closure reveals hierarchical dynamical organization” by Ziyang Wang, Qian-Yuan Tang, and Yueheng Lan. 

The code implements the scale-resolved local-closure framework developed in the manuscript and reproduces the main and supplementary analyses. All systems share a common implementation of local closure, observation-scale scanning, neighboring-scale similarity, and cross-resolution identification of persistent reorganization bands, with system-specific preprocessing kept in the corresponding figure scripts.

## Requirements

The scripts use Python 3 with `numpy`, `scipy`, and `matplotlib`. The adenylate-kinase analyses additionally require `mdtraj`.

Run the scripts from the project root so that the relative `data/` and `figures/` paths are preserved.

A practical production order is

```bash
python check_single_rule_null.py
python fig1.py
python fig2_lorenz.py
python fig3_ks.py
python fig4_adk.py
python figS1_two_regime.py
python figS2_rossler.py
python figS4_adk_noise.py
python figS5_havok_comparison.py
python figS3_record_robustness.py
```

`figS3_record_robustness.py` is best run last because it reuses the production representations and summary outputs of Figs. 2--4.

## Data generation

Raw trajectories for the Lorenz, Kuramoto--Sivashinsky, and Rössler systems are generated by the standalone scripts in `data-generation/`:

```bash
python data-generation/generate_lorenz_raw_data.py
python data-generation/generate_ks_raw_data.py
python data-generation/generate_rossler_raw_data.py
```

Each script reproduces the numerical settings used to generate the corresponding manuscript dataset and writes both the machine-readable NPZ file and a human-readable CSV export to `data/`. Data generation is kept separate from dimensional reduction, closure analysis, scale selection, and figure construction.

The three scripts are:

- `generate_lorenz_raw_data.py`: Lorenz trajectory and analytical velocity components.
- `generate_ks_raw_data.py`: 16-mode Kuramoto--Sivashinsky trajectory.
- `generate_rossler_raw_data.py`: Rössler trajectory and analytical velocity components.

## Python files

### `closure_pipeline.py`
Shared production implementation of the scale-resolved local-closure analysis. It computes windowed least-squares closure defects, the scale--time residual field, robust scale-wise temporal profiles, neighboring-scale similarity \(S(T)\), and persistent reorganization bands across nested logarithmic \(T\) grids. It also contains the numerical-resolution safeguard used before profile normalization and returns the full retained hierarchy together with the first reported characteristic scales.

### `figure_style.py`
Shared publication style for all figures: fonts, final-size typography, line widths, panel labels, and the common color convention for closure defects, reference signals, selected scales, and \(S(T)\).

### `fig1_synthetic.py`
Defines the controlled two-rule synthetic signal used in Fig. 1(c) and provides its reduced representation and scale-resolved closure analysis. The signal contains rapid switching between two local rotation rules with a slower modulation of their relative occurrence.

### `fig1.py`
Generates Fig. 1. Panels (a) and (b) illustrate the local-closure mechanism and analysis pipeline; panel (c) applies the shared production pipeline to the synthetic signal from `fig1_synthetic.py`.

### `fig2_lorenz.py`
Generates the Lorenz analysis in Fig. 2 from `data/lorenz_raw_data.npz`. It constructs the delay-coordinate representation, projects the exact Lorenz velocity into the retained subspace, runs the shared scale-selection pipeline, and adds Poincaré/trajectory information only as independent post-selection references.

### `fig3_ks.py`
Generates the Kuramoto--Sivashinsky analysis in Fig. 3 from `data/ks_raw_data.npz`. It uses the first 16 Fourier amplitudes, evaluates the truncated KS right-hand side analytically, constructs the reduced representation, and applies the shared scale-resolved closure pipeline.

### `fig4_adk.py`
Generates the analytical panels of the adenylate-kinase figure from `data/C1.0_1.dcd` and `data/closedCA.pdb`. The trajectory is aligned to the closed reference structure, represented by anchor-referenced Cartesian coordinates, and reduced using the 98% cumulative-energy criterion. The script produces the scale--time map, \(S(T)\), selected-scale closure traces, structural reference observables, and partial-coordinate comparisons. The structural rendering used for panel (a) is prepared separately.

### `figS1_two_regime.py`
Generates Supplementary Fig. S1, the controlled two-regime validation of the local-closure interpretation. A planar rotation switches between two angular velocities while remaining on the same geometric support. The script tests the predicted dependence on regime mixing, dynamical contrast, and midpoint timing.

### `figS2_rossler.py`
Generates Supplementary Fig. S2 from `data/rossler_raw_data.npz`. Only \(x\) and \(y\) enter the closure analysis; \(z\) is withheld and used afterwards as an independent reference for the large out-of-plane excursions. The script therefore provides a controlled partial-observation test.

### `figS3_record_robustness.py`
Generates Supplementary Fig. S3. The first row tests finite-record robustness by retaining the central 90% of each Lorenz, KS, and AdK reduced trajectory while keeping the representation fixed. The second row varies retained representation capacity around the production rank and compares the resulting \(S(T)\) organization and retained bands.

### `figS4_adk_noise.py`
Generates Supplementary Fig. S4, the AdK coordinate-noise test. Gaussian perturbations are added to the aligned CORE coordinates while the clean reduced basis and selected scales are held fixed. The script compares the clean and noisy standardized closure responses over several noise amplitudes and independent realizations.

### `figS5_havok_comparison.py`
Generates Supplementary Fig. S5, the direct Lorenz comparison with HAVOK. The HAVOK forcing coordinate is computed independently from the Lorenz trajectory and compared with the closure defect at the production long observation scale. HAVOK quantities do not enter closure-based scale selection.

### `check_single_rule_null.py`
Numerical sanity check for the shared pipeline. It applies the analysis to a single-rule synthetic signal, for which the closure residual is at numerical precision, and verifies that roundoff-level temporal variation is classified as unresolved rather than converted into a spurious scale hierarchy. This script is a diagnostic and does not generate a manuscript figure.

## Data files

### `data/lorenz_raw_data.npz`
Machine-readable Lorenz trajectory used by Fig. 2 and the Lorenz supplementary analyses. It contains time, \(x,y,z\), the analytical velocity components, and simulation metadata.

### `data/lorenz_raw_data.csv`
Human-readable export of the Lorenz trajectory and analytical derivatives. It mirrors the raw numerical data for inspection; the production figure scripts read the NPZ file.

### `data/ks_raw_data.npz`
Machine-readable Kuramoto--Sivashinsky trajectory used by Fig. 3. It contains the time grid, Fourier-mode amplitudes, and simulation parameters. The production script evaluates the modal velocity from the KS equations.

### `data/ks_raw_data.csv`
Human-readable export of the KS time series, with time followed by the Fourier-mode amplitudes. The production analysis reads the NPZ file.

### `data/rossler_raw_data.npz`
Machine-readable Rössler trajectory used by Supplementary Fig. S2. It contains time, \(x,y,z\), analytical derivatives, and the simulation parameters.

### `data/rossler_raw_data.csv`
Human-readable export of the Rössler trajectory and analytical derivatives. The production supplementary analysis reads the NPZ file.

### `data/C1.0_1.dcd`
This file contains the molecular dynamics trajectory of adenylate kinase utilized in Fig. 4 and the AdK supplementary analyses. Please note that this uploaded data contains only a 2.5% sample of the complete simulation. The full trajectory and reproducing code can be accessed at Zenodo:

### `data/closedCA.pdb`
Closed-state C-alpha reference structure for adenylate kinase. It provides the topology for the DCD trajectory and the structural reference used for alignment and anchor-referenced coordinates.

### `data/close.obj`
Three-dimensional surface/structure geometry used for the separately prepared AdK structural rendering.

### `data/close.mtl`
Material definition associated with `close.obj`.

## Outputs

Figure scripts write publication figures and compact numerical summaries to `figures/`. These outputs are generated from the shared pipeline and the system-specific representations described above.
